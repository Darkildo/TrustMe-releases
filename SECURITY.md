# Безопасность / Security

## Как сообщить об уязвимости

Не создавайте публичный issue. Напишите на **didakostya@gmail.com**: опишите проблему, версию приложения, платформу и шаги воспроизведения.
Если для демонстрации нужны файлы, не прикладывайте к письму свои ключи, резервные копии или переписку.

Вы получите ответ о том, принят ли отчёт, и о сроках исправления. Исправление выходит обычным релизом в этом репозитории.

## Reporting a vulnerability

Please do not open a public issue. Email **didakostya@gmail.com** with a description, the app version, the platform and steps to reproduce.
Do not attach your own keys, backups or conversations.

You will get a reply on whether the report is accepted and when a fix is expected. Fixes ship as a regular release in this repository.

## Поддерживаемые версии / Supported versions

Исправления безопасности выходят только для последней версии. / Security fixes are released for the latest version only.
