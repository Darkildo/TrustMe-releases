## Что умеет TrustMe

### Аккаунт без номера телефона
- Аккаунт создаётся на устройстве: вы проводите пальцем по экрану, и из этой случайности генерируется ваш ключ (Ed25519). Публичная часть ключа и есть ваш идентификатор.
- Номер телефона и почта не нужны. Номер можно указать по желанию — его увидят только подтверждённые контакты.
- Контакты добавляются по QR-коду или коду приглашения со сроком действия, в том числе одноразовому.

### Сеть доверия
- Отпечаток ключа собеседника можно сверить лично — контакт получит отметку «Сверен».
- Контакты делятся на сверенные, добавленные по рекомендации общих знакомых и неподтверждённые.
- Если ключ собеседника сменился, в чате появится предупреждение.
- Каждому контакту вы выдаёте и отзываете права: сообщения, звонки, контакты, история перемещений, сведения об устройстве.

### Переписка
- Ответы, реакции, редактирование, удаление у себя или у всех, закреплённые сообщения.
- Форматирование: жирный, курсив, зачёркнутый, моноширинный, скрытый текст.
- Фото, видео и файлы (до 10 за раз), альбомы, одноразовый просмотр медиа, встроенный редактор фото.
- Голосовые сообщения до 10 минут и видеосообщения-«кружки».
- Опросы: несколько ответов, анонимные, с автозакрытием.
- Стикеры: свои паки, импорт из архива, обмен паками в чате.
- Исчезающие сообщения — от часа до четырёх недель.
- Поиск по чату и по всем чатам, архив, закрепление, черновики, «Избранное».
- Отчёты о прочтении и статус «в сети» — с настройкой для каждого контакта отдельно.
- «Живой набор»: собеседник видит текст по мере набора — только если вы оба включили эту функцию.

### Группы
- Роли владельца и администраторов, режим «пишут только администраторы».
- Новым участникам доступна либо только новая переписка, либо вся история — выбирается при создании группы.
- Упоминания через @.

### Звонки
- Аудио- и видеозвонки один на один со сквозным шифрованием.
- Групповые звонки: до 5 участников по аудио и до 3 по видео.
- Показ экрана с компьютера (Windows и Linux), можно вместе со звуком. На телефоне показ экрана можно смотреть.
- Шумоподавление, в том числе нейросетевое на устройстве.
- Полноэкранный входящий звонок на Android, CallKit на iOS.

### Геолокация
- Трансляция местоположения выбранным контактам на 15 минут, час, 8 часов или до отключения.
- История перемещений с остановками и треками — видна только тем, кому вы дали это право. Экспорт в GPX.

### На компьютере
- Двухпанельный интерфейс, значок в трее, горячие клавиши, перетаскивание файлов, автозапуск.
- Светлая, тёмная и системная тема. Языки — русский и английский.

## Безопасность и приватность

**Шифрование.** Сообщения, медиа, геолокация и профиль шифруются на вашем устройстве и расшифровываются только у собеседника:
обмен ключами X25519, шифрование AES-256-GCM, подписи Ed25519. Звонки защищены DTLS-SRTP, а их сигнализация идёт по тому же зашифрованному каналу.
Соединение с сервером дополнительно защищено протоколом Noise.

**Защита прошлых сообщений (Forward Secrecy).** В личном чате можно включить дополнительный слой на основе Double Ratchet: ключ меняется с каждым сообщением,
и даже утёкший ключ или украденное устройство не раскроют уже доставленную переписку. Включается для каждого чата отдельно и только с согласия обеих сторон.
Группы и звонки этот слой не покрывает.

**Устройство.**
- Вход по PIN-коду (8 цифр) или паролю, плюс Face ID, Touch ID или отпечаток пальца.
- Автоблокировка через выбранное время; при желании — стирание данных после 10 неудачных попыток.
- Локальная база зашифрована (SQLCipher), файл ключа — Argon2id + AES-256-GCM.
- Шифрование медиа в памяти устройства — по желанию, ключ привязан к защищённому хранилищу устройства.
- На Android приложение запрещает скриншоты, а в списке открытых приложений содержимое скрыто на обеих мобильных платформах.

**Уведомления.** Сервер присылает только сигнал «проснись» — без текста. Устройство само получает и расшифровывает сообщение и показывает уведомление.

**Что видит сервер.** Содержимое сообщений сервер прочитать не может. Но ему известно, кто кому, когда и какого размера пишет, и ваш список контактов на уровне связей.
Недоставленные сообщения хранятся на сервере до 14 дней — в зашифрованном виде.

**Свой сервер.** В настройках можно указать другой узел — адрес, порт и его ключ — и сверить отпечаток узла.

**GIF и превью ссылок.** Поиск GIF работает через Tenor: Google увидит поисковый запрос и ваш IP-адрес. Функция необязательная.
Превью ссылки загружает устройство отправителя.

## Резервная копия и перенос

- **Перенос на новое устройство.** Новое устройство показывает QR-код, старое передаёт зашифрованный файл. Переезжают ключи, контакты и группы; сервер в переносе не участвует.
- **Резервная копия** — зашифрованный архив с паролем от 12 символов. Восстановление из неё создаёт **новый аккаунт**: обменяйтесь QR-кодами с контактами заново.
- Резервная копия хранится внутри приложения, пока вы её не экспортируете. Без переноса или копии потеря устройства означает потерю ключей и переписки.

## Установка

<details>
<summary><b>Android</b></summary>

1. Скачайте APK. Почти всем телефонам последних лет подходит `arm64-v8a`. Если не уверены — берите `universal`.
2. Откройте файл и разрешите установку из этого источника, когда система попросит.
3. Обновление — установите новый APK поверх старого. Переписка и ключи сохранятся.

</details>

<details>
<summary><b>Windows</b></summary>

1. Скачайте zip. Перед распаковкой: правый клик → «Свойства» → «Разблокировать» (если галочка есть).
2. Распакуйте в любую папку и запустите `TrustMe.exe`. Установщика нет.
3. Сборка не подписана сертификатом, поэтому SmartScreen покажет предупреждение: «Подробнее» → «Выполнить в любом случае».
4. Обновление — замените папку целиком. Данные лежат отдельно, в `%APPDATA%\com.requiem\TrustMe`, и сохранятся.

Крестик сворачивает окно в трей; выход — через меню значка в трее. Push-уведомлений на компьютере нет: сообщения приходят, пока приложение запущено.
Если пишет «Нет соединения» с ошибкой `os error 10013` — разрешите `TrustMe.exe` доступ в сеть в брандмауэре или антивирусе.

</details>

<details>
<summary><b>Linux</b></summary>

**.deb** (Ubuntu 24.04+, Debian 13, Mint 22) — зависимости подтянутся сами:

```sh
sudo apt install ./TrustMe-linux-x64.deb
```

**.tar.gz** (любой дистрибутив с glibc 2.38+, в том числе Fedora 40+) — распакуйте и запустите `./TrustMe`.
Системные библиотеки поставьте сами:

```sh
# Debian / Ubuntu / Mint
sudo apt install libgtk-3-0t64 libmpv2 libepoxy0 libsecret-1-0 \
     libayatana-appindicator3-1 libpulse0 pulseaudio-utils ffmpeg gnome-keyring
# Fedora
sudo dnf install gtk3 mpv-libs libepoxy libsecret \
     libayatana-appindicator-gtk3 pulseaudio-libs pulseaudio-utils ffmpeg-free gnome-keyring
```

- Ключи хранятся в системном хранилище секретов. Без запущенного gnome-keyring или KWallet приложение не запустится и объяснит почему.
- Показ экрана на Wayland требует xdg-desktop-portal и PipeWire; на X11 работает сразу.
- Данные лежат в `~/.local/share/com.requiem.trust_me`, обновление портативной сборки — замена папки.
- На Ubuntu 22.04 и других дистрибутивах со старой glibc сборка не запустится.

</details>

<details>
<summary><b>iOS</b></summary>

Сборки для iPhone распространяются через TestFlight по приглашению. Нужен iOS 15.6 или новее.

</details>

## Проверка подлинности файла

К каждому релизу приложены файлы `SHA256SUMS-android.txt`, `SHA256SUMS-windows.txt` и `SHA256SUMS-linux.txt`.
Сверьте сумму скачанного файла со строкой из списка:

```sh
sha256sum TrustMe-android-arm64-v8a.apk          # Linux
shasum -a 256 TrustMe-android-arm64-v8a.apk      # macOS
```
```powershell
Get-FileHash TrustMe-windows-x64.zip -Algorithm SHA256   # Windows
```

APK для Android подписаны одним ключом. Если система отказывается ставить обновление поверх установленной версии, значит файл подписан не тем ключом — не устанавливайте его.

## Ограничения, о которых стоит знать

- Один аккаунт — одно устройство. Синхронизации между несколькими устройствами одновременно нет; есть перенос аккаунта.
- Пересылать можно только полученные медиа: текст не пересылается, в группы — тоже.
- Push-уведомлений на Windows и Linux нет.
- На Linux нет записи видео с камеры и «кружков»; на Windows они есть.
- Обновления на компьютере ставятся вручную.
- Исчезающие сообщения удаляются у собеседника его приложением; гарантировать, что он не сохранил их другим способом, нельзя.
